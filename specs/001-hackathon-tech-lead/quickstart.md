# Demo Quickstart

1. Open this repository in Codex.
2. Ask: `Read AGENTS.md and inspect the repository. Propose a plan to add a short run section to README.md. Do not modify files yet.`
3. Review the goal, relevant files, proposed changes, and verification plan.
4. Reply: `Approved. Implement the plan.`
5. Ask for the final report: changed files, checks/results, and remaining risks.
6. Confirm the changed files match the approved plan with `git status` and `git diff`.
