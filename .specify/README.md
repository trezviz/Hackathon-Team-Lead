# Spec Kit Project Setup

This repository uses the Spec-Driven Development workflow:

1. `/speckit-constitution` updates the project constitution once.
2. `/speckit-specify` creates `specs/<number>-<slug>/spec.md`.
3. `/speckit-plan` adds research, design, and `plan.md`.
4. `/speckit-tasks` creates `tasks.md` grouped by user story.
5. `/speckit-implement` executes approved tasks and verifies the result.

The project-local Copilot skills live under `.github/skills/`. Choose a product or feature before starting `/speckit-specify`.
